# 导航页功能设计

**日期：** 2026-06-12
**状态：** 已确认

## 目标

为 LeiBlog 增加可由后台维护的前台导航页。导航页按分组展示网站卡片，参考现有图片中的分组网格与右侧目录布局；后台提供同页分组和网站管理，并支持拖拽排序与上下移动排序。

## 范围

本功能包括：

- 前台顶部一级导航入口“导航页”。
- 前台 `/navigation` 页面。
- 后台“导航页管理”，位于“贡献者管理”下方、“媒体库”上方。
- 两张导航数据表及公开、后台 API。
- 媒体库新增受保护系统文件夹“网址图标”。
- 分组和网站条目的创建、编辑、删除、移动与排序。

本功能不包括：

- 前台访客提交网站。
- 网站可用性定时检查。
- 自动抓取网站 favicon。
- 跨分组拖拽网站条目。

## 数据模型

### `navigation_groups`

| 字段 | 类型与约束 | 用途 |
| --- | --- | --- |
| `id` | `uuid`，主键 | 分组 ID |
| `name` | 非空，大小写不敏感唯一 | 分组名称 |
| `sort_order` | 非空整数 | 前后台展示顺序 |
| `created_at` | 非空时间戳 | 创建时间 |
| `updated_at` | 非空时间戳 | 更新时间 |

### `navigation_items`

| 字段 | 类型与约束 | 用途 |
| --- | --- | --- |
| `id` | `uuid`，主键 | 网站 ID |
| `group_id` | 外键，引用 `navigation_groups.id` | 所属分组 |
| `name` | 非空 | 网站名称 |
| `url` | 非空 | 网站网址 |
| `note` | 可空 | 网站备注 |
| `icon_url` | 可空 | 网站图标媒体地址 |
| `sort_order` | 非空整数 | 组内展示顺序 |
| `created_at` | 非空时间戳 | 创建时间 |
| `updated_at` | 非空时间戳 | 更新时间 |

删除分组使用限制策略：只允许删除空分组。数据库外键不级联删除网站，服务端在删除前检查组内网站数量并返回明确冲突错误。

排序值由服务端统一规范化为连续整数。新建分组排到所有分组末尾；新建网站排到所属分组末尾；网站移动到其他分组时排到目标分组末尾，并重新规范化原分组与目标分组顺序。

## 媒体库

在现有系统媒体文件夹列表中增加：

- 名称：`网址图标`
- slug：`website-icons`
- system key：`website-icons`
- 描述：`导航页网站图标只能存储到这里。`
- `is_protected = true`

该文件夹与“文章封面”“头像”“评论”“站点”一致：

- 媒体服务启动或读取文件夹时自动创建。
- 名称、描述、system key 和保护状态被修改后自动修复。
- 后台不能删除。
- 导航网站表单上传本地图标时固定上传到该文件夹。

图标为可选字段。未配置图标时，前台卡片展示默认链接图标或网站名称首字回退。

## 服务端架构

导航功能使用独立模块，避免继续扩大现有内容管理服务：

- 后台模块负责管理员鉴权、分组和网站 CRUD、移动及排序。
- 公开模块只负责返回前台导航页所需数据。
- 数据库迁移增加导航表、索引和更新时间触发器。

公开接口：

- `GET /navigation`
  - 返回按 `sort_order` 排序的非空分组。
  - 每个分组内返回按 `sort_order` 排序的网站。
  - 返回网站的 `id`、`name`、`url`、`note`、`iconUrl`。

后台接口：

- `GET /admin/navigation`
- `POST /admin/navigation/groups`
- `PATCH /admin/navigation/groups/:id`
- `DELETE /admin/navigation/groups/:id`
- `PUT /admin/navigation/groups/reorder`
- `POST /admin/navigation/items`
- `PATCH /admin/navigation/items/:id`
- `DELETE /admin/navigation/items/:id`
- `PUT /admin/navigation/items/reorder`

排序接口提交完整、有序且无重复的 ID 列表：

- 分组排序请求包含全部分组 ID。
- 网站排序请求包含目标分组 ID 与该组全部网站 ID。
- 服务端校验 ID 集合与数据库当前集合完全一致后，在事务中更新排序。
- 网站跨组移动通过网站编辑接口完成，不通过拖拽完成。

## 校验与错误处理

- 分组名称、网站名称、网站网址必填，保存前去除首尾空白。
- 分组名称大小写不敏感且不允许重复。
- 网站 URL 只允许 `http://` 或 `https://`。
- 备注和图标地址可为空。
- 删除非空分组返回冲突错误，并提示先移动或删除组内网站。
- 排序请求出现缺失、额外或重复 ID 时拒绝更新。
- 排序更新在事务中完成，避免部分排序被保存。
- 后台普通保存失败时保留表单内容并显示错误。
- 后台排序失败时恢复操作前顺序并显示错误。

## 前台页面

### 路由与入口

- 新增 `/navigation` 路由。
- 在前台顶部导航中增加一级入口“导航页”。
- 桌面顶部导航和移动抽屉导航均显示该入口。

### 页面布局

页面沿用当前博客主题、全局页头和响应式规则，主体参考提供图片：

- 主内容按分组纵向排列。
- 每个分组包含标题、分隔层级和网站卡片网格。
- 桌面端右侧显示粘性目录，列出当前页面中所有非空分组。
- 点击目录项平滑滚动到对应分组。
- 小屏幕隐藏右侧目录，主体占满可用宽度。
- 空分组不显示，也不出现在右侧目录。

网站卡片展示：

- 网站图标或回退图标。
- 网站名称。
- 可选备注。
- 整张卡片作为外部链接，使用新标签页打开，并设置 `noopener noreferrer`。

## 后台页面

新增 `/admin/content/navigation` 页面，并在内容管理侧栏中放置于“贡献者管理”下方、“媒体库”上方。

### 分组管理区

- 页面顶部展示分组列表与每组网站数量。
- 支持新建、重命名和删除空分组。
- 非空分组删除操作禁用，并说明需要先移动或删除组内网站。
- 点击分组切换下方网站管理区。
- 支持拖拽排序，以及键盘和移动端可用的上移、下移按钮。
- 拖拽完成或点击移动按钮后立即保存。

### 网站管理区

- 下方展示当前分组的网站管理表格。
- 支持新建、编辑和删除网站。
- 网站表单字段：名称、网址、备注、图标、所属分组。
- 图标可从媒体库选择或上传到 `website-icons` 文件夹。
- 修改所属分组时，网站移动到目标分组末尾。
- 当前分组内支持拖拽排序，以及上移、下移按钮。
- 拖拽完成或点击移动按钮后立即保存。
- 不支持通过拖拽跨分组移动。

### 排序交互

拖拽与上下移动共享同一排序保存逻辑：

1. 在客户端保存操作前顺序。
2. 乐观更新界面顺序。
3. 立即调用排序接口。
4. 成功后保留新顺序。
5. 失败后恢复操作前顺序并显示错误提示。

拖拽交互必须保留明确拖拽把手；上下移动按钮是移动端、键盘用户及拖拽失效时的完整替代操作。

## 测试策略

### 服务端

- 迁移测试验证两张导航表、索引、唯一约束、外键和更新时间触发器。
- 媒体测试验证“网址图标”文件夹自动创建、修复和不可删除。
- 后台接口测试覆盖分组和网站 CRUD。
- 测试非空分组禁止删除。
- 测试网站跨组移动后进入目标分组末尾，并规范化两组排序。
- 测试分组与网站排序接口成功路径和无效 ID 集合。
- 测试空名称、重复分组名称和非法 URL 协议。
- 公开接口测试验证空分组被过滤，并保持分组及网站排序。

### 前端

- 测试顶部一级导航包含“导航页”。
- 测试后台菜单中“导航页管理”位于贡献者管理下方。
- 测试前台不展示空分组。
- 测试外部卡片使用新标签页和安全 rel。
- 测试无图标网站使用回退显示。
- 测试网站图标上传使用 `website-icons` 文件夹。
- 测试分组和网站排序失败后恢复原顺序。

### 验证

- 运行数据库迁移、服务端测试和类型检查。
- 运行前端测试、检查和生产构建。
- 浏览器验证桌面端与移动端布局。
- 浏览器验证浅色和深色主题。
- 浏览器验证拖拽排序、上下移动、跨组移动、删除限制和外链打开行为。

## 验收标准

- 前台顶部导航存在一级“导航页”入口。
- `/navigation` 按已配置顺序展示所有非空分组及网站卡片。
- 桌面端有右侧目录，小屏幕布局可正常使用。
- 网站外链在新标签页安全打开。
- 后台可在同一页面管理分组和网站。
- 分组和网站均支持拖拽与上下移动，并在操作后立即保存。
- 非空分组无法删除。
- 网站可移动至其他分组。
- 图标可留空，也可通过受保护的“网址图标”媒体文件夹管理。
- 所有新增测试、现有测试、类型检查和构建通过。
